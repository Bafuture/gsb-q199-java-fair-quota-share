## 任务提示词

以下为本题完整的 User Prompt 原文，两次执行必须使用完全相同的文本。

我们多租户共享一份限流额度，之前大租户一上来就把额度抢光，小租户几乎没法用。请从零实现一个多租户配额公平分配组件。仓库目前只有一个空的 Maven 工程（pom.xml 只声明 JUnit 5 与 AssertJ）。要求：1) 支持为每个租户设置最小保障额度与最大上限，总和不超过全局额度；2) 支持保底分配：每个租户先拿到自己的保障额度，闲时额度可被他人借用；3) 支持借用与归还：借用方使用其它租户的闲置额度，原租户需要时要能逐步收回；4) 支持闲置检测：一段时间未使用的额度视为闲置并进入共享池；5) 支持公平性验证：在高并发抢占场景下，各租户实际获得量不得低于保障额度（需有测试证明）；6) 提供统计：各租户已用、保障、借用与收回量，以及全局剩余；7) 测试覆盖保底分配、借用与收回、闲置检测、并发下保障不被侵占与统计准确性；`mvn -q verify` 一条命令跑通。
